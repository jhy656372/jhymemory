# ipTIME NAS용 게시판 파일 업로드 기능 구현 계획

아! ipTIME 간이 NAS를 사용 중이시군요. 아주 탁월한 선택입니다! 👏
ipTIME NAS에는 기본적으로 **웹 서버(Apache)**와 **백엔드 프로그램(PHP)** 기능이 내장되어 있습니다. 

따라서 구글 파이어베이스 같은 외부 서비스를 새로 가입할 필요 없이, **현재 가지고 계신 ipTIME NAS를 '파일 창고'이자 '서버'로 바로 활용**할 수 있습니다.

## 구현 원리
1. 홈페이지 코드 안에 **PHP 언어**로 작성된 작은 서버 프로그램(`api/board.php`, `api/upload.php`)을 추가합니다.
2. 방문자가 게시판에 글과 파일을 올리면, 이 PHP 프로그램이 받아서 NAS의 하드디스크(`api/uploads` 폴더)에 안전하게 저장합니다.
3. 게시판에 들어오면, 저장된 글과 파일 목록을 다시 읽어와서 화면에 보여줍니다.

## User Review Required

> [!IMPORTANT]
> 이 작업을 진행하기 위해서는 ipTIME NAS 설정에서 **'Apache 서버'와 'PHP/MySQL' 기능이 켜져 있어야 합니다.** (보통 기본으로 켜져 있습니다.)
> 아래 계획을 보시고 동의하시면 바로 코딩을 시작하여, NAS 환경에 딱 맞는 홈페이지를 완성해 드리겠습니다!

## Proposed Changes

### 1. 백엔드(PHP) 파일 생성
홈페이지를 빌드할 때 같이 포함되도록 `public` 폴더 안에 API를 만듭니다.

#### [NEW] `public/api/board.php`
- 게시글 목록을 저장하고 불러오는 PHP 스크립트입니다. 데이터는 가벼운 `data.json` 파일에 저장합니다.
#### [NEW] `public/api/upload.php`
- 사용자가 업로드한 파일을 안전하게 NAS 하드디스크(`public/api/uploads` 폴더)에 저장해 주는 역할을 합니다.

### 2. 게시판 페이지 수정
#### [MODIFY] `src/pages/BoardPage.jsx`
- 기존의 가짜 데이터 대신, 우리가 만든 `board.php`에서 **실제 저장된 게시글**을 가져오도록 수정합니다.
- 화면 하단에 **[글쓰기] 버튼**을 추가합니다.
- 글쓰기 버튼을 누르면 제목, 내용, **첨부 파일**을 선택할 수 있는 팝업(모달) 창이 뜹니다.
- 작성 완료 시 NAS로 파일이 전송되고, 즉시 게시판 목록에 표시됩니다.

## Verification Plan

### Manual Verification
1. 제가 코딩을 완료하면, 평소처럼 **`SERVER_BUILD.bat`** 파일을 실행합니다.
2. 만들어진 `dist` 폴더 안의 내용물을 통째로 복사해서 **ipTIME NAS의 홈페이지 폴더(보통 `html` 또는 `public_html`)**에 덮어씌웁니다.
3. 스마트폰이나 외부 PC에서 NAS 주소로 접속한 뒤, 게시판에서 글을 쓰고 파일을 올려봅니다.
4. 파일이 잘 올라가고 다운로드가 되는지 확인합니다.
