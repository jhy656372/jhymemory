# AI 음악 프롬프트 및 가사 메이커 앱 구축

멋진 음악 프롬프트와 가사를 쉽게 만들 수 있는 웹 애플리케이션을 구축합니다. 사용자가 쉽게 옵션을 선택하고 텍스트를 입력하면 AI 음악 생성기(Suno, Udio 등)에 바로 복사하여 붙여넣을 수 있는 결과물을 만들어줍니다.

## User Review Required

> [!IMPORTANT]
> **앱의 작동 방식 확인**
> 현재 웹 브라우저 자체적으로 AI 텍스트 생성 기능이 내장되어 있지 않기 때문에, 이 앱은 사용자가 선택한 **[장르, 분위기, 시간, 템포, 보컬] 옵션을 조합하여 완벽한 '영어 프롬프트'를 자동으로 생성해 주는 생성기(Builder)** 역할을 하게 됩니다. 
> 가사의 경우, 선택한 분위기에 맞는 멋진 템플릿(미리 만들어진 가사 틀)을 제공하거나, 사용자가 직접 영감을 받아 적을 수 있는 예쁜 에디터 화면을 제공할 예정입니다. 이 방향이 마음에 드시나요?

> 2. 추가하고 싶은 입력 항목이 더 있나요? (현재: 주제, 분위기, 시간, 보컬, 템포)

## Proposed Changes

Vite와 React를 사용하여 빠르고 아름다운 최신 웹 앱을 구축합니다.

### Frontend Application (Vite + React)
* **프레임워크 설정:** `npx create-vite` (React, JavaScript)
* **UI/UX 디자인:** 부드러운 애니메이션, 글래스모피즘(유리 같은 반투명 효과), 트렌디하고 감각적인 디자인. (TailwindCSS 대신 CSS를 사용하여 직접 섬세하게 제어합니다.)
* **주요 기능:**
  1. **입력 섹션:** 드롭다운과 텍스트 입력창을 통해 사용자가 원하는 옵션(분위기, 보컬 등)을 쉽게 선택.
  2. **결과 섹션:** 완성된 AI 프롬프트를 한눈에 보고 '복사' 버튼으로 쉽게 가져갈 수 있는 UI.
  3. **가사 탭:** 영감을 주는 가사 템플릿과 직접 작성할 수 있는 텍스트 에디터.

## Verification Plan

### Manual Verification
1. `npm run dev`를 통해 개발 서버를 실행하고 로컬 호스트에서 브라우저를 엽니다.
2. 아름다운 디자인이 잘 적용되었는지, 입력값이 프롬프트 결과창에 즉시 반영되는지 확인합니다.
3. 복사 버튼이 제대로 작동하는지 테스트합니다.
